# Certificados C&L — QR Permanente

Repositorio de páginas de verificación de certificados de competencias laborales.

- Cada certificado tiene su página en `/cert/{uuid}/index.html`
- URL pública: `https://patricionhoocc-afk.github.io/certificados/cert/{uuid}/`
- Administrado automáticamente por `cert_engine.py`

**No editar manualmente — los archivos son generados por script.**
